# NAOJ MIRI MRS ワークショップ

English version: [README.md](README.md)

国立天文台（NAOJ）で開催される **JWST MIRI MRS データ解析** の1日ハンズオン・ワークショップ用の教材です。講師は Matthias Samland です。

このワークショップでは、JWST 中間赤外線装置 中分解能分光器（MIRI MRS）のインテグラルフィールド分光データを使った解析を、最初から最後まで実際に手を動かしながら学びます。具体的には、開発環境の準備 → 較正パイプラインの実行 → 分子輝線や広がった放射の科学的解析、という流れです。

Python の基礎的な使い方を知っていることを前提とします。JWST に触ったことがなくても大丈夫です。

## ワークショップ前の準備：環境のインストール

セットアップは **2 段階** に分かれています。当日までに両方とも済ませておいてください。特に JWST パイプラインや CARTA のインストールは時間がかかることがあり、講義室でトラブルシュートするより家でやっておくほうが楽です。

### Step 1 — Python の科学計算環境をつくる

自分の OS に合わせて、以下のガイドを参照してください：

- **macOS / Linux のかた:** [installation_instructions/macos_linux.md](installation_instructions/macos_linux.md)
- **Windows のかた:** [installation_instructions/windows.md](installation_instructions/windows.md)（WSL2 経由で進めます。ワークショップで使うツールのいくつかは Unix 系の環境でしか動かないためです）

ここでは Miniforge（conda + mamba）をインストールし、ベースとなる `astro` Python 環境をつくり、VS Code と git もセットアップします。

### Step 2 — ワークショップ用のパッケージをインストールする

OS 側の環境ができたら、次のガイドに進んでください：

- [installation_instructions/workshop_packages.md](installation_instructions/workshop_packages.md)

ここでは **CARTA**（スペクトルキューブのビューア）をインストールし、**`mrs_analysis`** という mamba 環境（JWST パイプラインとワークショップで使う解析ライブラリ一式）と、分子輝線解析の GUI ツール用の **`iSLAT`** 環境を別々につくります。

### Step 3 — データをダウンロードする

ワークショップで例として使うデータは、こちらからダウンロードできます：
<https://datashare.mpcdf.mpg.de/s/5W8PB89Yea7BWjY>

もし「基本のチュートリアルが終わったら、自分の興味のある天体でも試してみたい」というかたは、**事前に何を見てみたいか考えておく** とスムーズです。MAST アーカイブで、その天体の MIRI/IFU データがあるか確認しておきましょう。

## ハンズオンで実際にやること

ハンズオンでは、次のような流れで進めます：

1. **データの取得** — MAST で SY Cha の MRS 観測データを探し、観測提案書 PDF で背景を確認したうえで、較正済みの `s3d`（キューブ）と `x1d`（1次元スペクトル）をひとつのフォルダにダウンロードします。
2. **キューブを眺める** — CARTA で開いて、ぱっと見でわかる特徴（分子の輝線群、原子輝線、シリケイト feature の放射 / 吸収）を探します。
3. **連続光（コンチニュアム）の差し引き** — 1次元スペクトルに対して Temmink et al. (2024) の連続光差し引きを実行し、フィットが妥当か目で確認します。輝線探しの前に必須のステップです。
4. **iSLAT による分子輝線解析** — 連続光を差し引いたスペクトルを iSLAT 用に整形し、いろいろな分子種・温度の LTE スラブモデルを重ねて、どんな分子が見えているかを同定します。
5. *(オプション)* **広がった輝線放射** — `extended_structures` ノートブックを使い、キューブ内で空間的に広がっている原子・分子輝線をマッピングします。

自分が興味を持っている天体があれば、ぜひそれを持ってきてください。なければ SY Cha がデフォルトです。

# ハンズオン本編：MIRI 中分解能分光器（MRS）

ハンズオンは、アーカイブから取得した較正済みデータ → 原始惑星系円盤の実際のスペクトル → 分子輝線の同定、という一本道のワークフローを通して進めます。デフォルトのターゲットは **SY Cha** ですが、他の天体でも手順はまったく同じです。まずは SY Cha で全ステップを通して感覚をつかみ、時間があればお気に入りの天体で同じことをやってみてください。

## Step 1. データの取得（MAST から Stage-3 プロダクトをダウンロード）

- MAST ポータルで、自分のターゲットの MIRI MRS 観測を検索します。とりあえずは **SY Cha** を使いましょう。MAST の advanced search で MIRI/IFU とターゲット座標で絞り込み、さらに条件を狭めていきます。
- 観測提案書 PDF を読んで、観測モード、ディザーパターン、露光時間、もとの観測計画の科学目的などを把握します。MAST の検索結果で「…」をクリックして "Show detail" を開くと Proposal ID がわかるので、「JWST proposal id XXX」で Google 検索するか、直接 <https://www.stsci.edu/jwst-program-info/program/?program=XXX> を開いてください。
- **Level-3 較正済みプロダクト** をダウンロードします（`*_s3d.fits` のキューブと `*_x1d.fits` の 1次元スペクトル）。これは STScI が公開してくれている較正パイプラインの出力なので、自分でパイプラインを回す必要はありません。MRS は 12 個のサブバンドに分かれているので、x1d と s3d がそれぞれ 12 ファイルずつあるはずです。
- ダウンロードしたファイルは、ターゲットごとに 1 つのフォルダにまとめます（ワークショップでは `data/<target>/stage3_mast/` の構成を使います）。同梱のサンプルデータ `data/SYCha/stage3_mast/` がまさにこの構成なので、それに合わせれば OK です。MAST が遅いときは、この GitHub に書かれているリンク（README.md 参照）からもダウンロードできます。

## Step 2. CARTA でデータを確認する

- `*_s3d.fits` のキューブを CARTA で開き、データの状態を確認します。天体が FOV の中央あたりに来ているか、目立つアーティファクトがないか、などをチェックしてください。Widgets → Profiles から "Spectral Profiler" を選ぶと、画像上にカーソルを乗せた位置のスペクトルが表示されます（あるいは View → Layout → Cube Analysis を選ぶと、3D キューブ向けのデフォルトのレイアウトが立ち上がります）。
- 左下のインスペクタで画像のスケールを調整して、画像内の構造がちゃんと見えるようにしておきましょう。
- スペクトルチャンネルを順に切り替えて、画像と PSF が波長とともにどう変わっていくか観察してみてください。
- 目で見ただけでもわかるサイエンス的な特徴を探してみましょう。分子輝線の forest、原子輝線（例：[Ne II]、[Ar II]）、10 µm 付近の幅広いシリケイト feature、中心天体まわりに広がっている放射、などです。
- このタイミングで、MRS の各サブバンド（1A → 4C）が波長方向にどのようにタイル状に並んでいるかも体感しておくとよいです。

## Step 3. x1d スペクトルを 1 本の 1 次元スペクトルにつなぐ

- ダウンロードした `*_x1d.fits` ファイルが入っているフォルダを指定して、[`MRSReduction/combine_x1d_spectra.py`](MRSReduction/combine_x1d_spectra.py) を実行します。
- このスクリプトは、12 個のサブバンドが波長の重複領域でうまく一致するようにスケールをそろえ、重複のない 1 本のスペクトル（1A → 4C）にまとめます。出力は `<source>_spectrum_full.csv` と `<source>_spectrum_stitched.csv`、それに確認用の診断 PNG です。
- 診断プロットを必ず確認しましょう。サブバンド間のズレが極端に大きい場合は、たいていスクリプトのバグではなく、較正の問題か抽出アパーチャの取り方の問題です。

## Step 4. つないだスペクトルから連続光を差し引く

- Step 3 でつくったスペクトルに対して、[`MRSReduction/continuum_subtraction.py`](MRSReduction/continuum_subtraction.py)（Temmink et al. 2024 のアルゴリズムの実装）を実行します。
- これは iSLAT で分子輝線を扱う前に必須のステップです。スラブモデルは「輝線だけのスペクトル」にフィットするものであって、「連続光が支配的なスペクトル」にフィットするものではないからです。
- 診断プロットを見て、連続光がもっともらしくトレースされているか確認します。輝線の forest を overfit していないか、シリケイト feature を underfit していないか、などです。おかしければパラメータを調整してやり直してください。

## Step 5. iSLAT で分子輝線を解析する

- 連続光を差し引いた CSV のカラム名を、iSLAT が読める形式に変えます（つないだスペクトルの出力ファイルのうち "for_i" がついているものがありますが、それを参考に整形してください）。
- そのスペクトルを iSLAT で開きます。iSLAT は専用の `iSLAT` 環境で動く、独立した GUI ツールです。
- いろいろな分子種（H₂O、CO、CO₂、HCN、C₂H₂、OH など）について、温度や柱密度を変えながら LTE スラブモデルを重ね描きして、どの分子が存在しそうか、励起状態はどのくらいか、を見ていきます。

## （オプション）Step 6. 広がった輝線放射を探す

- [`extended_emission/extended_structures.ipynb`](extended_emission/extended_structures.ipynb) を開きます。
- このノートブックは、整備された `linelist_combined.csv` を使い、Level-3 キューブの中で空間的に広がった原子・分子の輝線（ジェット、アウトフロー、光蒸発による wind など）を探します。Step 3〜5 でやった「空間的に積分した 1 次元スペクトル解析」と相補的な情報が得られます。

## （時間があれば）Step 7. 別の「答えを知らない」天体で同じことをやってみる

- まだ見たことのない別の MIRI MRS ターゲットを MAST から選びます。SY Cha とは違う種類の天体（たとえばデブリ円盤、Class II 円盤、進化した星など）を選ぶと面白いです。
- ワークショップでの手取り足取りなしで、Step 1 → 5 を新しいデータで繰り返してみてください。SY Cha だけでなく自分でもこの流れを再現できるか確認する、そして「答えを知らない状態」でぶつかる疑問を自分で炙り出す、というのが目的です。

## （上級者向け、ディスクと回線に余裕があれば）Step 8. 生データから較正パイプラインを走らせる

- 今度は Level-3 ではなく、**Stage-0 の未較正生データ** を MAST からダウンロードします（数十 GB になることがあり、ワークショップ会場の Wi-Fi では時間がかかります。当日実際に走らせるかは現実的に判断してください）。
- [`MRSReduction/simplified_pipeline_script.py`](MRSReduction/simplified_pipeline_script.py) を実行する（あるいは `JWPipeNB-MIRI-MRS.ipynb` を 1 セルずつ進めていく）と、Stage 1〜3 を自分で通すことができます。
- 自分で reduction した `*_x1d.fits` と、MAST にある Level-3 プロダクトを比べてみましょう。各パイプライン・ステージが実際に何をしているか、そしてデフォルト設定が自分のサイエンスにとって十分頑健かどうかを体で理解するのに、これが一番の近道です。
